Tama STAGE — USB-UART RAM Loader & Setlist Sync

Chrome / Edge の Web Serial API（460,800 baud）で、実機のフラッシュを書き換えずに RAM 一時実行と CSV セットリスト送信を行います。

1. USB-UART 接続（FT232RNL / 3.3V ロジック）

※ 配線は TXD / RXD / GND の3本のみ（VCC は絶対に接続しないでください）。

2. RAM 一時ロード実行（Download 画面から）

本体で Planet → A → Connect → Download → Download を開いた状態で tama_stage.bin を選択して送信します。電池を抜けば純正 ROM に戻ります。
